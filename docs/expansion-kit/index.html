RTNode Expansion Kit Test

A test build for Heltec's WiFi LoRa 32 Expansion Kit, touch screen version: the first kit or Kit V2. Flash it from your browser — no Python or tools required.

This is a test build, not a release. It is RTNode v1.0.54 with one change: it drives the kit's colour screen instead of the V4's small OLED. The screen shows the same two panels as the OLED, at twice the size: the node's name, frequency and address on top, the status icons below. Touch and the kit's buttons do nothing; the V4's own button works as usual.

There are two kits with different boards, each with its own image. The page picks the image from the board's memory: 2 MB for the first kit (a V4), 8 MB for Kit V2 (a V4 R8).

It has not been run on a kit yet. On bare boards it runs normally and passes our tests, so the radio, WiFi, Bluetooth and setup portal should behave as on any V4. On a board outside a kit the screen stays blank. For a board not in a kit, use the main flasher.

Step 3 — Tell us what you see

Unplug and replug the kit after flashing. Then send these to us where you asked for this build:

  1. Which kit it chose: the first kit or Kit V2.
  2. A photo of the screen about 10 seconds after power-up, and one after setup once it's running.
  3. Is it the right way up, with the node's name, frequency and address on top and the status icons below? Is any text mirrored?
  4. Is it white text on black? (Black on white means the colours are inverted.)
  5. If the screen stays dark or shows noise, say so, and if you can, send the USB serial log from power-up (115200 baud).
  6. Anything else that behaves differently from a normal V4.

Requirements
  • ✓ Google Chrome 89+ or Microsoft Edge — Web Serial API required (Firefox and Safari are not supported)
  • ✓ USB cable connected to the V4 in the kit
  • ✓ No Python, esptool, or PlatformIO installation needed
  • ⚠ On Linux, you may need to add your user to the dialout group: sudo usermod -a -G dialout $USER (then log out and back in)
