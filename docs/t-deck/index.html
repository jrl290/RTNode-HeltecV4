RTNode T-Deck Test

A test build of RTNode for the LILYGO T-Deck. Flash it from your browser — no Python or tools required.

This is a test build, not a release. It is RTNode v1.0.54 on the T-Deck. The screen shows the same two panels as a Heltec's small screen, side by side at twice the size: the node's name, frequency and address on the left, the status icons on the right. The trackball's click is RTNode's one button. The keyboard, the touch screen and rolling the trackball do nothing.

It has run on one T-Deck so far. For any other board, use the main flasher.

Use a USB-A cable or hub. The T-Deck doesn't connect to a Mac over a USB-C to USB-C cable: no port appears at all.

Step 1 — Detect

Connect the T-Deck by USB and switch it on, then click Detect and pick its port.

Step 3 — Tell us what you see

After flashing, set the node up through its portal: join the WiFi network RTNode-Setup and open 10.0.0.1. Then send these to us where you asked for this build:

  1. A photo of the screen once it's running.
  2. Is it the right way up, with the keyboard at the bottom? Is any text mirrored?
  3. Does a short click of the trackball wake the screen?
  4. If the screen stays dark or shows noise, say so, and if you can, send the USB serial log from power-up (115200 baud).
  5. Anything else that behaves differently from RTNode on a Heltec.

Requirements
  • ✓ Google Chrome 89+ or Microsoft Edge — Web Serial API required (Firefox and Safari are not supported)
  • ✓ A USB-A cable or hub connected to the T-Deck
  • ✓ No Python, esptool, or PlatformIO installation needed
  • ⚠ On Linux, you may need to add your user to the dialout group: sudo usermod -a -G dialout $USER (then log out and back in)
