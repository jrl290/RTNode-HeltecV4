RTNode Board Check

Find out what's on your LoRa board, so RTNode can support it. It runs in your browser, with nothing to install.

What this does: it puts a small check program on your board, finds the radio, screen and buttons by itself, and asks you to press a few buttons. At the end you get a short report to send us. Nothing is transmitted over the radio.

The check replaces the firmware on your board, but leaves its saved settings alone. Afterwards, put RTNode on with a First install from the RTNode flasher, or Meshtastic with its web flasher. For now the check runs on boards with an ESP32-S3 chip.

Simulated board (this page was opened with ?sim): no real board is used.

The page checks each file against its SHA-256 before writing it. The check program's source is in the board-check folder of RTNode's feature/board-check branch, GPL-3 like the rest of RTNode. Its list of boards is made from the board definitions of the Meshtastic firmware project (GPL-3), with thanks.

Requirements
  • ✓ Google Chrome 89+ or Microsoft Edge — Web Serial API required (Firefox and Safari are not supported)
  • ✓A USB cable that carries data, plugged into the board
  • ⚠ On Linux, you may need to add your user to the dialout group: sudo usermod -a -G dialout $USER (then log out and back in)
